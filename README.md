# ⏰ Digital Clock with Time-Based Alerts

## 📌 Introduction
This **Digital Clock** is a simple and interactive web application built using **HTML**, **CSS**, and **JavaScript**. It displays the current time in real-time and allows users to set custom time-based reminders such as **Wake Up Time**, **Lunch Time**, and **Nap Time**. Once a time is set, the application updates messages and background visuals to match the selected activity, creating an engaging user experience.

## ✨ Features
- ⏲️ Real-time digital clock display (hours, minutes, seconds, AM/PM)
- 🛌 Set custom **Wake Up Time**
- 🍽️ Set **Lunch Time**
- 😴 Set **Nap Time**
- 💬 Dynamic message updates and background changes based on selected time
- 📱 Fully responsive layout for all screen sizes

## 🎯 Design Decisions or Assumptions
- Used **setInterval()** in JavaScript to update the clock every second
- Time comparison logic is based on 12-hour format with AM/PM
- All alerts and visuals are triggered on exact hour match
- Project kept lightweight with no external libraries for better performance
